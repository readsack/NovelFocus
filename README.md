## NovelFocus
A small, minimal, aesthetic, focus timer application which works entirely on your local machine. It even has tracking of your focus hours! All data is stored in the browser's local storage.

## Features
1. Daily focus sessions
2. Monthly time tracking

## Getting Started
**To Run It On Your Local Machine**
1. Clone the repo
2. run ```npm i``` followed by ```npm run dev```
3. Click the link in the terminal to see the local instance.

## Stack
This website is a static website, built entirely on [Svelte](https://svelte.dev/)
